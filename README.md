# pairwise-meshlet-culling

远处整座山突然消失，近处小石头却一直在画，转视角时三角形像纸片一样闪：meshlet 包围锥的半径按顶点平均算，细长三角形被误判为背面；法线锥半角用包围盒对角线，窄长 meshlet 的锥角过大，整簇被错误剔除；索引缓冲用 8 位，超过 255 顶点的 meshlet 静默回绕；LOD 边界处两个 meshlet 的边界顶点不重合，接缝出现裂缝；GPU 驱动间接绘制时实例 ID 和 meshlet ID 打包进同一个 32 位字段，高位溢出后画错簇；遮挡剔除查询用的是上一帧 HZB，相机快速前进时山体被旧深度剔掉；实例变换矩阵在任务着色器里读错 bank，缩放后的 meshlet 飞出屏幕；meshlet 数量超过间接缓冲上限，尾部簇被丢弃；图元裁剪把退化三角形和背面一起剔，轮廓边缘出现空洞；索引压缩用 16 位局部索引但顶点数超过 64K，远处模型闪面；meshlet 包围盒在蒙皮后没更新，角色动作时手臂被自身包围盒剔除；调试视图和正式管线用两套裁剪，画面上看不到的簇仍在提交。render/meshlet_culling.py 是核心，tests/test_meshlet_culling.py 15个红。要修的是：包围锥半径；法线锥；索引位宽；LOD 接缝；ID 打包；HZB 时效；实例数据；缓冲上限；图元裁剪；局部索引；蒙皮包围盒；调试一致。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

子方向：图形渲染；任务类型：Bugfix；语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
